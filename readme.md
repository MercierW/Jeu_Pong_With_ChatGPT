# Jeu Pong




🏓 Pong en JavaScript (ES6 Modules)
Un jeu de Pong simple en JavaScript utilisant les modules ES6 (import/export).
Contrôlez les raquettes et marquez des points en faisant rebondir la balle ! ⚡

📂 Structure du projet
bash
Copier
Modifier
/pong-game
│── index.html        # Page principale
│── style.css         # Styles CSS
│── /js               # Scripts du jeu
│   │── main.js        # Boucle principale
│   │── paddle.js      # Gestion des raquettes
│   │── ball.js        # Gestion de la balle
│   │── controls.js    # Gestion des entrées clavier
│   │── utils.js       # Fonctions utilitaires
🎮 Commandes
Joueur 1 🏆

🔼 Z → Monter
🔽 S → Descendre
Joueur 2 🏆

🔼 Flèche Haut → Monter
🔽 Flèche Bas → Descendre
